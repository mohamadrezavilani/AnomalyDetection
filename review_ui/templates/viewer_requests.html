مرور مستقل / RequestID

فهرست درخواست‌ها

هر ردیف یک RequestID مستقل است؛ حتی دو استعلام از یک قبضِ یکسان، دو درخواست جدا هستند.

این فهرست در حالت بدون Session شامل درخواست‌های تمام نشست‌هاست؛ اندازه صفحه به معنی شمار فعالیت یک شخص نیست.

با فیلتر Session و «عملیات تجاری»، خط زمانی همان نشست را در همین صفحه می‌بینید. پیش‌فرض فقط درخواست‌های دارای API اصلی را نشان می‌دهد. نقش تجاری، پشتیبان، مدیریتی، سیستمی و ناشناخته قابل فیلتر است. خطوط SQL و Cache همان درخواست در جزئیات آن دیده می‌شوند.
