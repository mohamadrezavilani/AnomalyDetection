# فایل‌های مرجع خارج از GitHub

نسخهٔ عمومی شامل کد توسعه، Fixtureهای مصنوعی، Patch و خلاصهٔ قابل انتشار است. برای کار روی شاهد واقعی، از مالک نسخهٔ مجاز فایل‌های مرتبط را بگیر.

| فایل | کاربرد |
|---|---|
| `P24_AD_P0_Evaluator_Handoff_20261108.zip` | گزارش تفصیلی P0، رسیدهای NativePG/Shadow، ابزارهای اصلی آزمون و بستهٔ Viewer R3. |
| `P24_AD_Release_20261108_WinStart.zip` | بستهٔ نصب‌شدنی مرجع با Manifest کامل و فایل‌های اصلی. |
| `P24_Viewer_R3_Install_Source_20261107.zip` | سورس Viewer و قرارداد منبع. برای بررسی آفلاین، Runtime نامزد R3 از `payload/candidate.zip` در بستهٔ Viewer استخراج می‌شود. |
| خروجی پذیرش مرحلهٔ سوم و Capture مجاز | برای بررسی RequestID و provenance واقعی، بازپخش همسان و تصمیم نهایی مدل. دسترسی و انتقال آن‌ها با مالک پروژه است. |

فایل `PUBLIC_SOURCE_PROVENANCE.json` اثرانگشت فایل‌های واردشده از Release و Patch را مشخص می‌کند. آزمون عمومی با Manifest کامل نسخهٔ عملیاتی و گزارش پذیرش سرور دامنهٔ متفاوتی دارد.
